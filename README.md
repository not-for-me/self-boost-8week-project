# Self Boosting 8 Weeks Project

**8주간의 집중 프로젝트를 통해 AI Data Manager로 성장하기**

## 🎯 프로젝트 목표

이 저장소는 AI 기술 기반의 Data Manager로서ㅈ 필요한 실무 역량을 8주 동안 집중적으로 쌓기 위한 자기개발 프로젝트입니다.
단순한 이론 학습이 아닌, 실제 서비스 가능한 수준의 프로젝트를 직접 구현하면서 데이터 엔지니어링과 AI/ML 실무 경험을 쌓습니다.

## 💼 역할 분석

- 데이터 수집, 분석, 가공, 평가, 관리 전반의 프로젝트 운영
- AI 모델 개발을 위한 학습 데이터 구축 및 벤치마크 데이터셋 설계
- Python 기반의 데이터 처리 파이프라인 구축
- HuggingFace, OpenCV 등 AI/ML 라이브러리 활용
- 팀 간 협업을 통한 데이터 품질 관리

이 프로젝트는 위 역량들을 실제로 사용해보며 체득하는 것을 목표로 합니다.

## 📁 프로젝트 구조

```
self-boost-8week-project/
├── projects/           # 개별 프로젝트들
│   └── [프로젝트명]/   # 각 프로젝트는 독립적인 모듈로 구성
├── til/                # 매일의 학습 기록 (Today I Learned)
│   └── tpl.md         # 일일 기록 템플릿
├── CLAUDE.md          # AI 어시스턴트를 위한 컨텍스트 문서 (영문)
└── README.md          # 이 파일
```

## 🛠️ 기술 스택

- **언어**: Python 3.14
- **패키지 관리**: uv (빠른 Python 패키지 설치 및 관리 도구)
- **프로젝트 관리**: 개별 프로젝트는 `projects/` 디렉토리 하위에 모듈 단위로 구성
- **문서화**: TIL(Today I Learned) 시스템으로 매일의 학습과 진행 상황 기록

## 📚 프로젝트 목록

### Project 1: 재무제표 인식 시스템 (Table Recognition)

**목표**: 증권사 PDF 리포트에서 재무제표를 자동으로 인식하고, 재무 데이터에 대한 질문에 답변하는 소형 LLM 시스템 구축

**구현 내용**:
- PDF 문서에서 표 형태의 재무제표 검출 및 추출
- 재무제표 구조 인식 (계정과목, 금액, 기간 등)
- 추출된 데이터에 대한 자연어 질의응답 인터페이스
- 소형 LLM 파인튜닝 또는 프롬프트 엔지니어링

**습득 역량**:
- 문서 처리 및 OCR 기술
- 구조화된 데이터 추출 파이프라인 구축
- LLM 통합 및 프롬프트 설계
- 도메인 특화 모델 적응

### 향후 프로젝트 (계획)

8주 프로그램이 진행되면서 추가될 프로젝트들은 다음 역량들을 목표로 합니다:
- 데이터 파이프라인 자동화
- 멀티모달 데이터 처리 (텍스트, 이미지, 정형 데이터)
- 평가 프레임워크 설계 및 구현
- 프로덕션 레벨의 데이터 관리 시스템

## 📝 일일 학습 시스템 (TIL)

`til/` 디렉토리에서 매일의 학습과 작업을 체계적으로 기록합니다:

- **오늘 목표**: 계획한 작업
- **실제 한 것**: 새벽/저녁 세션별 성과
- **배운 것**: 핵심 학습 내용 1-3줄 요약
- **막힌 것 / 질문**: 문제와 해결 방향
- **수치 기록**: 정량적 진행 상황 추적
- **내일 할 것**: 다음 액션 아이템
- **커밋**: 당일 커밋 메시지
- **이동 시간 활용**: 통근 중 학습 내용 (선택)

이러한 기록은:
- 진행 상황 추적 및 동기 부여
- 문제 해결 과정의 아카이빙
- 꾸준한 학습 습관의 증거
- 기술 개념 설명 연습

## 🚀 시작하기

### 새 프로젝트 시작

```bash
cd projects
mkdir [프로젝트명]
cd [프로젝트명]
uv init
uv venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
```

### 일일 기록 작성

```bash
cd til
cp tpl.md 2026-01-20-d01.md  # 날짜와 D-day 형식으로 파일명 생성
# 에디터로 오늘 할 일과 진행 상황 기록
```
