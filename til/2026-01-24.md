## 배운 것

### 1. Protocol vs ABC
```python
# Protocol: 구조적 서브타이핑 (duck typing)
class IMetadataManager(Protocol):
    def is_duplicate_url(self, url: str) -> bool: ...

# ABC: 명목적 서브타이핑 (명시적 상속 필요)
class ResultExporter(ABC):
    @abstractmethod
    def export(self, result: ProcessingResult) -> None: ...
```
- Protocol: 기존 클래스 수정 없이 인터페이스 준수 가능 (테스트 용이)
- ABC: 명시적 상속으로 의도 명확, 추상 메서드 강제

### 2. 의존성 소유권 추적
```python
class ReportScraper:
    def __init__(self, ..., downloader=None):
        self._owns_downloader = downloader is None

    def close(self):
        if self._downloader and self._owns_downloader:
            self._downloader.close()  # 생성한 것만 정리
```
