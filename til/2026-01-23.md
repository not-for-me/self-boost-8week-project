### 메모

#### End-to-End 워크플로우 확인 완료

```
PDF → fin-stat-table-detector → images/ + labels.json
                                      ↓
                               annotation-workspace/
                               data/local-files/
                                      ↓
                               Label Studio UI
                               (수동 검수)
                                      ↓
                               annotations.json
                                      ↓
                               data-evaluator
                               (Precision/Recall/F1)
```

전체 파이프라인 연결 완료. 이제 각 컴포넌트 품질 개선에 집중할 차례.

#### 실제 사용 명령어

```bash
# 1. 테이블 탐지 및 이미지 생성
uv run fin-stat-table-detector detect ../data/SK증권/ \
    -o ./sk_broker_labels.json \
    -i ./sk_broker/ \
    -d sk_broker \
    -p -w 4

# 2. 이미지를 annotation-workspace로 이동
mv ./sk_broker/* ../annotation-workspace/data/local-files/

# 3. Label Studio 실행
cd ../annotation-workspace
./scripts/start.sh
```
