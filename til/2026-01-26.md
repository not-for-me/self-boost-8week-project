## 배운 것

### 1. Linear Regression → Logistic → Softmax 흐름

```
Linear Regression
    ↓ (이진 분류로 확장)
Logistic Regression: σ(Wx + b) → [0, 1]
    ↓ (다중 클래스로 확장)
Softmax Regression: softmax(Wx + b) → 확률 분포
```

### 2. 손실 함수의 자연스러운 확장

| 모델 | 출력 | 손실 함수 |
|------|------|----------|
| Linear | 연속값 | MSE: $(y - \hat{y})^2$ |
| Logistic | 확률 | BCE: $-[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ |
| Softmax | 확률분포 | CE: $-\sum y_i \log\hat{y}_i$ |

### 3. Sigmoid vs Softmax

```python
# Sigmoid: 각 출력 독립적 → 이진 분류, 멀티레이블
sigmoid(z) = 1 / (1 + e^(-z))  # 각각 [0,1]

# Softmax: 모든 출력 합 = 1 → 멀티클래스 (상호 배타적)
softmax(z_i) = e^(z_i) / Σe^(z_j)  # 합이 1
```

### 4. Gradient Descent 핵심

```python
# 경사하강법 업데이트
W = W - lr * ∂Loss/∂W

# PyTorch 패턴
optimizer.zero_grad()  # 기울기 초기화
loss.backward()        # 역전파로 기울기 계산
optimizer.step()       # 파라미터 업데이트
```

### 메모

#### Regression 모델 비교

```
                    Linear          Logistic         Softmax
출력 범위           (-∞, +∞)        [0, 1]           [0, 1] (합=1)
활성화 함수         없음             Sigmoid          Softmax
손실 함수           MSE             BCE              Cross-Entropy
사용 사례           회귀             이진 분류         다중 클래스 분류
```

#### PyTorch 기본 학습 루프

```python
for epoch in range(epochs):
    # Forward
    hypothesis = model(X)
    loss = criterion(hypothesis, Y)

    # Backward
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

#### Cross-Entropy Loss 직관

- 정답 클래스의 예측 확률이 높을수록 loss 낮음
- $-\log(p)$: p=1이면 0, p→0이면 ∞
- 틀린 예측에 큰 페널티 부여
