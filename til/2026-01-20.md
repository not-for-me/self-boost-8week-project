## 배운 것

### 1. Union-Find (Disjoint Set Union)

**문제 상황**: 여러 탐지기(pdfplumber, camelot)가 같은 표를 중복 탐지할 때, **전이적 중첩**을 처리해야 함

```
A↔B 겹침, B↔C 겹침 → A↔C가 직접 안 겹쳐도 같은 표
단순 IoU 비교: A-B 병합, C 별도 (잘못됨)
Union-Find: A, B, C 모두 같은 그룹 (정확함)
```

**핵심 연산**:
- `find(x)`: x가 속한 집합의 대표(루트) 반환
- `union(x, y)`: x와 y를 같은 집합으로 병합

**최적화 기법**:
- **경로 압축 (Path Compression)**: find 시 부모를 루트로 직접 연결 → 이후 find O(1)
- **랭크 기반 합집합 (Union by Rank)**: 작은 트리를 큰 트리 아래에 붙임

**시간 복잡도**: 거의 O(1) - 정확히는 O(α(n)), α는 아커만 함수의 역함수

### 2. Spatial Indexing

**문제**: n개 bbox의 모든 쌍 비교 = O(n²) → n=100이면 10,000번 비교

**해결**: 공간 인덱스로 **겹칠 가능성 있는 후보만** 빠르게 검색

#### R-Tree
- 2D 사각형을 계층적으로 인덱싱
- MBR(Minimum Bounding Rectangle) 기반 탐색
- 범위 쿼리: O(log n + k), k는 결과 개수

#### Interval Tree
- 1D 구간을 인덱싱 (X축, Y축 별도 관리)
- 2D 겹침 = X축 겹침 ∩ Y축 겹침
- Python 라이브러리: `intervaltree`

```python
# 2D 영역 겹침 = X축과 Y축 모두 겹쳐야 함
x_candidates = x_tree.overlap(bbox.x0, bbox.x1)
y_candidates = y_tree.overlap(bbox.y0, bbox.y1)
return x_candidates & y_candidates
```

### 3. 통합 알고리즘 (Union-Find + Spatial Index)

```
1. Spatial Index로 겹칠 후보 빠르게 검색 O(log n)
2. IoU 계산으로 실제 겹침 확인 (threshold: 0.3)
3. Union-Find로 전이적 그룹화
4. 각 그룹에서 대표 선택 (가장 큰 bbox)
```

**성능 비교** (n=100 기준):
| 방식 | 비교 횟수 | 복잡도 |
|------|----------|--------|
| 단순 비교 | ~10,000 | O(n²) |
| Union-Find + Spatial | ~700 | O(n log n) |

### 4. IoU (Intersection over Union)

두 bbox가 얼마나 겹치는지 측정하는 지표 (0~1)

```python
IoU = 교집합 면적 / 합집합 면적
```

- `1.0`: 완전 동일
- `0.5`: 절반 겹침
- `0.3`: 일부 겹침 (병합 임계값으로 적합)
- `0.0`: 전혀 안 겹침

### 5. Label Studio 좌표 시스템

Label Studio는 **퍼센트 기반 좌표(0-100)**를 사용. PDF 포인트 좌표를 변환:

```python
x_percent = (bbox.x0 / page_width) * 100
y_percent = (bbox.y0 / page_height) * 100
```

### 6. Click CLI 패턴

```python

@click.option("--dry-run", is_flag=True)
def detect(input_path, dry_run): ...

main.add_command(detect)
```
